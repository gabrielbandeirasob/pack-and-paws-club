# Pack & Paws Club Mobile

Expo SDK 57 / React Native 0.86 application using Expo Router.

## Run

```bash
npm install
npm start
```

For a browser preview:

```bash
npm run web
```

## Quality gates

```bash
npm test
npm run typecheck
npx expo-doctor
npm run web:export
```

## Current product slice

- Premium manager dashboard
- Operational dispatch board
- Five manager tabs
- Manager/driver navigation policy
- Shared branded design tokens

The screens currently use representative fixture data. Backend authentication, contacts, schedules and route optimization are the next implementation phases.
