The app itself is finished and already in Apple's review. The icon is the **first thing every client

## What we need (any ONE of these is enough)

| Option | File | Notes |
|---|---|---|
| **Best** | The **vector** original | `.svg`, `.ai`, `.eps` or `.pdf` — we can generate every size perfectly |
| Good | **PNG, 1024×1024 px or larger** | *For the app icon:* **solid background**, no transparency, no rounded corners (Apple applies the rounding itself) |
| Good | **PNG, 1024×1024 px or larger, transparent** | For the in-app screens (splash / login) |

If you have both a background version and a transparent version, please send **both**.
